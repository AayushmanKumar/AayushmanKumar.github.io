# TradeTrack Analytical Tool

Quantitative analysis on 1M+ trade logs, building modular LangGraph signal tools and FastAPI services, reducing order failure by 30%.

## Overview

Designed at Apricity TS to extract trade signals and recommend optimal entry-exit decision-making for algorithmic traders.

## Key Contributions

- **1M+ Trade Log EDA**: Performed exploratory data analysis on 1,000,000+ trade execution logs to uncover user behavior patterns, API latency bottlenecks, and slippage points.
- **LangGraph Agentic Flows**: Formulated modular signal extraction nodes within LangGraph, allowing AI agents to dynamically query market depth, volatility, and order fill ratios.
- **FastAPI Microservices**: Built low-latency REST endpoints verified through Postman and surfaced on an interactive Streamlit analytics dashboard.
- **Custom Loss Functions**: Trained classification and segmentation models for order failure prediction.

## Outcomes

- Reduced order failures by 30% through cohort-wise alert systems and latency-driven anomaly detection.
- Boosted operational visibility across 5 financial markets, enabling the launch of 2 high-frequency execution features.
