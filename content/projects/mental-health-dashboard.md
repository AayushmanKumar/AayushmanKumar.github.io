# Mental Health Big Data Dashboard

Big data visual analytics platform processing 292,000+ responses to extract demographic patterns across 17+ attributes with D3.js visual dashboards.

## Overview

Developed as part of CS661 (Big Data Visual Analytics) under Prof. Soumya Dutta at IIT Kanpur. Built by a cross-functional team across analytics, backend data pipelining, and interactive D3.js visualization.

## Key Highlights

- **292,000+ Responses**: Scalable data cleaning, imputation, and categorical encoding using Pandas and Scikit-learn.
- **Interactive D3 Visualizations**: Coordinated multi-view dashboard featuring sunburst charts, parallel coordinate plots, and choreopleth maps.
- **Dimensionality Reduction**: Integrated PCA and t-SNE projections to identify hidden cluster correlations across workplace stress factors.
